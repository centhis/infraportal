# Документация по API (v1)

Этот документ описывает все эндпоинты, доступные в API v1 бэкенда.

## Общие Принципы

-   **Версионирование**: Все маршруты API находятся под префиксом `/api/v1`.
-   **Аутентификация**: Большинство эндпоинтов требуют аутентификации с помощью JWT (JSON Web Token). Токен доступа (access token) должен быть передан в заголовке `Authorization` как `Bearer <token>`.
-   **Авторизация**: Доступ к ресурсам (пользователи, группы, роли) контролируется системой разрешений (permissions). Необходимые разрешения указаны для каждого эндпоинта.
-   **Пагинация**: Эндпоинты, возвращающие списки объектов (например, `GET /users/`, `GET /groups/`), поддерживают пагинацию с помощью query-параметров `skip` (смещение) и `limit` (количество элементов).

## Ресурс: Auth (`/auth`)

Эндпоинты для аутентификации, управления сессиями и получения информации о текущем пользователе.

| Метод | Путь                 | Описание                                                              | Аутентификация | Разрешения |
| :---- | :------------------- | :-------------------------------------------------------------------- | :------------- | :--------- |
| `POST`  | `/login`             | Аутентифицирует пользователя по логину/паролю. Устанавливает `refresh_token` в httpOnly cookie. Возвращает `access_token` и список разрешений. | Не требуется    | -          |
| `GET`   | `/refresh`           | Обновляет `access_token`, используя `refresh_token` из cookie.            | Требуется cookie | -          |
| `GET`   | `/verify`            | Проверяет валидность текущего `access_token`.                          | Обязательна    | -          |
| `POST`  | `/logout`            | Завершает сессию пользователя, удаляя `refresh_token` из базы и cookie. | Требуется cookie | -          |
| `GET`   | `/me`                | Возвращает информацию о текущем аутентифицированном пользователе.     | Обязательна    | -          |
| `GET`   | `/sessions`          | Возвращает список активных сессий текущего пользователя.            | Обязательна    | -          |
| `DELETE`| `/sessions/{session_id}` | Завершает (отзывает) указанную сессию текущего пользователя.           | Обязательна    | -          |

## Ресурс: Users (`/users`)

Эндпоинты для управления пользователями.

| Метод | Путь                 | Описание                                    | Аутентификация | Разрешения   |
| :---- | :------------------- | :------------------------------------------ | :------------- | :----------- |
| `GET`   | `/`                  | Возвращает список пользователей с пагинацией. | Обязательна    | `users:view` |
| `POST`  | `/`                  | Создает нового пользователя.                | Обязательна    | `users:create` |
| `GET`   | `/{user_id}`         | Возвращает пользователя по его ID.          | Обязательна    | `users:view` |
| `PUT`   | `/{user_id}`         | Обновляет данные пользователя по его ID.      | Обязательна    | `users:update` |
| `DELETE`| `/{user_id}`         | Удаляет пользователя по его ID.             | Обязательна    | `users:delete` |
| `GET`   | `/by-login/{login}`| Возвращает пользователя по его логину.       | Обязательна    | `users:view` |
