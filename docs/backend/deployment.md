# Развертывание (Deployment)

## Docker

Бэкенд упакован в Docker-образ на базе `python:3.12-slim`.

### Сборка и Запуск

Мы используем **uv** внутри контейнера для быстрой установки зависимостей.

1. **Базовый образ**: `python:3.12-slim`.
2. **Зависимости**: `uv` устанавливает пакеты в системный Python (`--system`), что уменьшает размер образа за счет отсутствия виртуального окружения.
3. **Команда запуска**: При старте контейнера автоматически выполняются миграции (`alembic upgrade head`), после чего запускается сервер (`uvicorn ...`).

### `Dockerfile`
Файл находится в корне `backend/`. 

```bash
# Сборка образа
docker build -t infraportal-backend .

# Запуск
docker run -p 8000:8000 --env-file .env infraportal-backend
```

## Автоматические Миграции

В данной конфигурации миграции применяются автоматически при каждом запуске контейнера ("Auto-Migrate on Startup").
Это упрощает развертывание (не нужен отдельный init-container), но требует внимательности при откате версий (downgrade не автоматизирован).
