# LDAP Settings

## Описание
Подмодуль **LDAP Settings** управляет параметрами подключения и интеграции с LDAP-сервером (Active Directory, OpenLDAP).

## Модель данных (`LdapSetting`)

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | Integer | Уникальный идентификатор. |
| `key` | String | Уникальный ключ (например, `LDAP_URI`, `LDAP_BIND_PASSWORD`). |
| `value` | String | Значение настройки. Пароли хранятся в зашифрованном виде (bcrypt). |
| `type` | String | Тип данных (`'string'`, `'int'`, `'bool'`, `'password'`). |
| `is_sensitive` | Boolean | Флаг чувствительности. Для паролей (`LDAP_BIND_PASSWORD`) всегда должен быть `True`. |

## Безопасность
*   Поле `LDAP_BIND_PASSWORD` (и другие `is_sensitive`) никогда не возвращается в открытом виде через API. Вместо этого клиент получает маскированное значение (`***`).
*   При обновлении `LDAP_BIND_PASSWORD` значение автоматически шифруется перед сохранением в БД.
*   Сервисный слой дешифрует пароль только внутри приложения для установления соединения.

## API Эндпоинты

Префикс: `/api/v1/settings/ldap`

### Получение списка
**GET** `/`
*   **Права**: `settings:view`

### Проверка статуса включения
**GET** `/is_enabled`
*   **Права**: Доступно **любому аутентифицированному пользователю**.
*   **Ответ**: `true` или `false`.

### Тестирование подключения
**POST** `/test`
*   **Права**: `settings:update`
*   **Тело запроса**:
    ```json
    {
      "ldap_uri": "ldap://server:389",
      "ldap_bind_dn": "cn=admin",
      "ldap_bind_password": "secret_password",
      "ldap_search_base": "dc=example,dc=com",
      "ldap_user_filter": "(uid={0})"
    }
    ```
*   **Описание**: Проверяет возможность подключения с указанными (временными) параметрами, не сохраняя их в БД.

### Обновление настройки
**PUT** `/{key}`
*   **Права**: `settings:update`
*   **Особенности**: Если обновляется пароль, он передается в открытом виде, но сохраняется зашифрованным.

## Ключевые настройки

*   `LDAP_ENABLED` (bool): Глобальный переключатель интеграции.
*   `LDAP_URI` (string): Адрес сервера (например, `ldap://192.168.1.10:389` или `ldaps://server:636`). TLS определяется автоматически по протоколу.
*   `LDAP_BIND_DN` (string): DN пользователя для подключения (Bind User).
*   `LDAP_BIND_PASSWORD` (password): Пароль Bind User.
*   `LDAP_BASE_DN` (string): Базовый DN для поиска пользователей.
*   `LDAP_USER_FILTER` (string): Дополнительный фильтр поиска (например, `(memberOf=cn=groups,...)`).
*   `LDAP_SYNC_SCHEDULE` (string): Расписание синхронизации в формате cron (например, `0 0 * * *`).
