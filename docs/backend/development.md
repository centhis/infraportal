# Руководство Разработчика (Development Guide)

Этот документ описывает основные процессы разработки бэкенда: управление зависимостями, запуск локального окружения и контроль качества кода.

## 1. Управление Зависимостями (`uv`)

Мы используем [uv](https://github.com/astral-sh/uv) — современный и экстремально быстрый менеджер пакетов для Python.

### Основные команды

#### Установка зависимостей
Синхронизация виртуального окружения с файлом `uv.lock` (или `pyproject.toml`, если lock-файла нет):
```bash
uv sync
```

#### Добавление библиотеки
Добавить пакет в `pyproject.toml` и установить его:
```bash
uv add <package_name>
```

#### Добавление Dev-зависимости
Для библиотек, нужных только при разработке (тесты, линтеры):
```bash
uv add --dev <package_name>
```
Пример: `uv add --dev pytest`

#### Удаление библиотеки
```bash
uv remove <package_name>
```

#### Обновление Lock-файла
Если вы изменили `pyproject.toml` вручную или хотите обновить версии транзитивных зависимостей:
```bash
uv lock
```

## 2. Локальный Запуск

### Бэкенд
```bash
cd backend
# Активация окружения (если не активно)
source .venv/bin/activate
# Запуск сервера
sh start.sh
```
Сервер будет доступен по адресу `http://localhost:8000`.
Документация Swagger: `http://localhost:8000/docs`.

### Celery Worker
```bash
cd celery_worker
# Установка зависимостей воркера (отдельное окружение!)
uv sync
sh start_worker.sh
```

## 3. Контроль Качества (QA)

### Линтинг (Ruff)
Мы используем `ruff` для проверки стиля кода и поиска ошибок.
```bash
# Проверка
uv run ruff check .

# Авто-исправление
uv run ruff check . --fix
```

### Тестирование (Pytest)
Запуск всех тестов:
```bash
uv run pytest
```
*Настройки тестов и фильтры предупреждений находятся в `pytest.ini`.*
