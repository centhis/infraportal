# Core Settings

## Описание
Подмодуль **Core Settings** отвечает за управление общими системными настройками.

## Модель данных (`CoreSetting`)

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | Integer | Уникальный идентификатор записи. |
| `key` | String | Уникальный строковый ключ настройки (например, `SITE_TITLE`). |
| `value` | String | Значение настройки. Хранится как строка. |
| `type` | String | Тип данных для приведения значения: `'string'`, `'int'`, `'bool'`, `'json'`. |
| `is_sensitive` | Boolean | Флаг чувствительности данных. Если `True`, значение маскируется (`***`) при отдаче через API. |

## API Эндпоинты

Все эндпоинты имеют префикс `/api/v1/settings/core` и требуют аутентификации.

### Получение всех настроек
**GET** `/`
*   **Права доступа**: `settings:view`
*   **Ответ**: Список объектов настроек. Чувствительные данные маскируются.

### Получение настройки по ключу
**GET** `/{key}`
*   **Права доступа**: `settings:view`
*   **Параметры**: `key` (ключ настройки)
*   **Ответ**: Объект настройки.

### Обновление настройки
**PUT** `/{key}`
*   **Права доступа**: `settings:update`
*   **Тело запроса**: `{"value": "новое значение"}`
*   **Ответ**: Обновленный объект настройки.

## Пример использования (Service Layer)

```python
from app.db.database import SessionLocal
from app.settings.core import services

db = SessionLocal()

# Получение значения в нужном типе (например, int или bool)
timeout = services.get_core_setting_value(db, "SESSION_TIMEOUT") 
```
