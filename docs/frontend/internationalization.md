# Документация по Интернационализации (i18n)

Интернационализация (сокращенно i18n) — это процесс адаптации приложения для поддержки нескольких языков. В проекте используется фреймворк `i18next` в связке с `react-i18next`.

## Конфигурация (`i18n.js`)

Основной файл конфигурации — `frontend/src/i18n/i18n.js`.

В отличие от подхода с асинхронной загрузкой переводов по HTTP, в нашем проекте все файлы локализаций **импортируются напрямую** и встраиваются в итоговый бандл приложения.

```javascript
// i18n.js
import commonEN from './locales/en/common.json';
import commonRU from './locales/ru/common.json';

const resources = {
  en: { common: commonEN },
  ru: { common: commonRU },
};

i18n.init({
    resources,
    // ...
});
```

**Ключевые параметры конфигурации:**
-   `resources`: Объект, содержащий все переводы, сгруппированные по языку и пространству имен (namespace).
-   `use(LanguageDetector)`: Подключает плагин, который автоматически определяет язык пользователя на основе настроек браузера или сохраненного значения в `localStorage`.
-   `fallbackLng: 'en'`: Язык, который будет использоваться, если язык пользователя не поддерживается или не был определен.
-   `ns`: Массив "пространств имен" (`'common'`, `'auth'`, `'layout'`, `'user_management'`). Это позволяет разделять переводы на логические группы.
-   `defaultNS: 'common'`: Пространство имен по умолчанию.

## Провайдер (`I18nProvider.jsx`)

Компонент `frontend/src/app/providers/I18nProvider.jsx` является кастомной оберткой, которая выполняет две функции:
1.  Оборачивает приложение в стандартный `I18nextProvider`, передавая ему сконфигурированный экземпляр `i18n`. Это делает функции перевода доступными во всем приложении.
2.  Создает собственный `I18nContext`, который предоставляет:
    -   `currentLanguage`: Текущий выбранный язык.
    -   `changeLanguage`: Функцию для смены языка.
    
Этот контекст используется для создания UI-компонентов, позволяющих пользователю вручную переключать язык. Выбранный язык сохраняется в `localStorage`.

## Структура переводов

Все файлы переводов находятся в `src/i18n/locales/`. Структура следующая:
```
locales/
├── en/
│   ├── auth.json
│   ├── common.json
│   ├── layout.json
│   └── user_management.json
└── ru/
    ├── auth.json
    ├── common.json
    ├── layout.json
    └── user_management.json
```
-   Каждый язык имеет свою директорию (`en`, `ru`).
-   Внутри каждой директории находятся JSON-файлы, имена которых соответствуют пространствам имен (`ns`) из конфигурации.
-   Файлы содержат пары "ключ-значение".

**Пример (`ru/common.json`):**
```json
{
  "save": "Сохранить",
  "cancel": "Отмена"
}
```

## Использование в компонентах

Для использования переводов в компонентах предназначен хук `useTranslation` из `react-i18next`.

```jsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  // Загружаем пространство имен 'user_management'
  const { t } = useTranslation('user_management');

  return (
    <div>
      <h1>{t('title')}</h1> {/* Ключ 'title' из user_management.json */}
      
      {/* Можно использовать ключ из defaultNS ('common') без указания нэймспейса */}
      <button>{t('save')}</button> {/* Ключ 'save' из common.json */}
    </div>
  );
}
```
Хук `useTranslation` можно вызывать с указанием пространства имен или без него (в таком случае будет использоваться `defaultNS`).
