# Проект Infraportal

Добро пожаловать в документацию проекта Infraportal. Этот документ предоставляет высокоуровневый обзор всей системы, включающей как бэкенд, так и фронтенд.

## Обзор Проекта
Infraportal — это веб-приложение, предназначенное для управления инфраструктурой. Оно состоит из двух основных частей:

-   **Бэкенд**: Реализован на Python с использованием фреймворка FastAPI. Отвечает за логику бизнеса, взаимодействие с базой данных, аутентификацию, авторизацию и предоставление API для фронтенда.
-   **Фронтенд**: Разработан на JavaScript с использованием библиотеки React. Предоставляет пользовательский интерфейс для взаимодействия с бэкендом.
